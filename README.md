## Features

<div align="left">

* Automatically Disable, Hide, Stop or Suspend apps
* Support Root, Shizuku, Dhizuku and more
* Create Actions to open multiple apps at the same time
* Backup/Restore lists, settings and preferences
* Incredibly fast
* And much more...
